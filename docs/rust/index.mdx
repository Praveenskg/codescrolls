# Rust - Complete Learning Path

Rust is a systems programming language focused on **safety**, **speed**, and
**concurrency** — without a garbage collector. It powers browsers, databases,
CLIs, embedded systems, and cloud services.

## Why Learn Rust?

- Memory safety without GC pauses
- Fearless concurrency with strong compile-time checks
- Zero-cost abstractions and predictable performance
- Growing industry demand (WebAssembly, backends, tooling)

## Prerequisites

- Basic programming experience (variables, loops, functions)
- Comfort with a terminal / CLI
- Rust toolchain via [rustup](https://rustup.rs/) (stable channel)

## Suggested Learning Flow

1. Finish Basics in order — especially ownership and borrowing.
2. Practice Intermediate topics with small CLI crates.
3. Move to Advanced and ship one end-to-end project.

## Mini Project Ideas

- CLI file organizer (ownership, `Path`, `Result`)
- JSON config tool (structs, serde, error handling)
- Concurrent downloader (threads or async + `tokio`)
