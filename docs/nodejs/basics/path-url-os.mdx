# Path, URL, and OS

Core modules help you handle paths, parse URLs, and read host info safely.

## path

```js
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const full = path.join(__dirname, 'data', 'users.json');
console.log(path.basename(full)); // users.json
console.log(path.extname(full)); // .json
```

## URL

```js
const url = new URL('https://api.example.com/v1/users?active=true');
console.log(url.pathname); // /v1/users
console.log(url.searchParams.get('active')); // true
```

## os

```js
import os from 'node:os';

console.log(os.platform());
console.log(os.cpus().length);
console.log(os.homedir());
```

## Common Pitfalls

- Hardcoding `C:\` or `/home/...` paths
- Assuming `__dirname` exists in ESM
- Parsing URLs with string splits instead of `URL`

3. Print free memory with `os.freemem()`.
