# Node.js - Complete Learning Path

Node.js lets you run JavaScript on the server. It is built on Chrome's V8 engine
and uses a non-blocking, event-driven model — ideal for APIs, CLIs, realtime
apps, and tooling.

## Why Learn Node.js?

- One language across frontend and backend
- Huge npm ecosystem
- Excellent for I/O-heavy services and developer tools
- Strong demand for fullstack and backend roles

## Prerequisites

- Solid JavaScript (ES6+: promises, async/await, modules)
- Comfort with the terminal
- Node.js LTS installed ([nodejs.org](https://nodejs.org/))

## Suggested Learning Flow

1. Finish Basics and build a small CLI that reads/writes files.
2. Build an Express API in Intermediate.
3. Add auth, a database, tests, and deploy in Advanced.

## Mini Project Ideas

- Notes CLI (fs, path, argv)
- URL shortener API (Express, JSON file or SQLite)
- Auth-protected todo API (JWT + Postgres)
